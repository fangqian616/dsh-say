给 DSH 的语音插件 A voice plugin for DSH

用你喜欢的
声音说话 Speak in a voice
you like

装完就能用 —— 默认走系统语音，零下载、零 Python、零显卡。想要角色声线，再接入 GPT-SoVITS。 It works the moment you install it — the default backend is your operating system’s own voices. No download, no Python, no GPU. Install GPT-SoVITS later for character voices.

$ dsh plugin --profile web add dsh-voice

报告会先压缩再朗读。一份 500 字的汇报整篇念完要 100 秒 —— 比读它还慢。 Reports are compressed before being spoken. A 500-character report read in full takes about 100 seconds — slower than reading it.

三步Three steps

从零到听见它说话From nothing to hearing it speak

  1. 01

    装插件Install

    在 profile 的组合文件里加一行，重启。工具立刻出现在智能体手上。Add one row to your profile composition and restart. The tools appear to the agent immediately.

  2. 02

    让它说话Hear it

    说一句"把早安念出来"。默认用系统语音，不需要任何下载。Say “speak good morning out loud”. The system voice answers — no download involved.

  3. 03

    想要别的嗓子再说Change the voice later

    一条命令装上随仓库附带的声线，或者带上你自己的。首次加载会问你三个问题，答案自己落盘。One command installs the voice shipped with the repository, or bring your own. First load asks three questions and writes the answers down.

汇报模式Report mode

念给耳朵听的，不是写给眼睛看的Written for the eye, spoken for the ear

tts_report 先把长报告压成短稿再朗读。中文语音实测约 5 字/秒 —— 500 字整篇念完要 100 秒，用户会直接关掉声音。 tts_report compresses a long report before speaking it. Chinese speech measures about 5 characters per second, so 500 characters read in full takes 100 seconds — long enough that people mute it.

原文Source 500 字chars
朗读Spoken 120 字chars

压缩是本地句序排序，零额外模型调用。完整度可以通过 budget 调整。 Compression is local sentence ranking with no extra model call. Adjust how much survives with budget.

声线Voices

仓库不带声线，但带你验证的那一条No voice is bundled, but one is shipped to verify with

随仓库附带Shipped with the repository

参考音和声线定义在仓库里，权重单独取 —— 因为单个文件 148 MB，超过 GitHub 的 100 MB 上限。The reference clip and pack definition live in the repository; the weights are fetched separately, because the checkpoint alone is 148 MB and GitHub rejects files over 100 MB.

$ node scripts/install-voice.mjs

一条命令：取权重、找引擎、放到位、登记。不用手动下载，也不用自己找文件夹。One command: fetch, locate the engine, install, register. Nothing to download by hand and no folder to find.

用你自己的Bring your own

给一段 3-10 秒干净人声和它的逐字文本，登记成声线包即可。人设与声线是分开的 —— 同一个人设可以换声线，同一个声线也能换人设。Give a 3–10 second clean clip and its exact transcript, and register it as a pack. Persona and voice are separate: one persona can wear several voices.
